# Customer-Segmentation-Analysis
This Task Tell the analysis of the Customer Segmentation Analysis using python(scikit learn).

Project Overview

This project focuses on analyzing customer behavior and dividing customers into different groups based on their purchasing patterns, annual income, spending habits, and demographics. The main objective is to help businesses understand their customers better and improve decision-making through targeted marketing strategies.

Using Python libraries such as Pandas, Matplotlib, Seaborn, and Scikit-learn, customer data is cleaned, processed, visualized, and segmented using the K-Means Clustering algorithm.

Objectives
Analyze customer demographic and behavioral data
Identify different customer groups based on spending patterns
Perform clustering using Machine Learning techniques
Visualize customer segments for business understanding
Generate insights for targeted marketing and customer retention

Project Workflow
1. Data Collection

A custom customer dataset was created in CSV format containing customer demographic and purchasing information.

2. Data Preprocessing
Loaded dataset using Pandas
Checked missing values and data types
Converted categorical values into numerical format using Label Encoding
Selected important features for clustering
3. Feature Scaling

StandardScaler was used to normalize the data because clustering algorithms are sensitive to feature scale.

4. Customer Segmentation

Applied the K-Means Clustering algorithm to divide customers into different groups based on income and spending behavior.

5. Data Visualization

Used Matplotlib and Seaborn to create:

Elbow Method graph
Customer segmentation scatter plot
Cluster comparison analysis
